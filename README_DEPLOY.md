# DATÓMICO Website V4

Versión V4 de la landing oficial de DATÓMICO.

## Actualización en GitHub / Vercel
1. Sustituye los archivos del repositorio `vizualpublicidad/datomico-tv` con el contenido de esta carpeta.
2. Conserva `index.html`, `styles.css`, `script.js`, `vercel.json` y la carpeta `assets` en la raíz.
3. Haz commit en la rama `main`, por ejemplo: `DATOMICO website V4`.
4. Vercel desplegará automáticamente el commit.
